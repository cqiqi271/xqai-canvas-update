怎么更新

1打开你的画布，点击右上角 「在线更新」 图标（版本号旁边）。
2点 「检查更新」，看到新版本后点 「一键更新」，程序会自动下载、备份并替换文件。
3更新失败或想换回旧版，在更新窗口里点 「回滚」 即可恢复。
更新完成后按 Ctrl + F5 强制刷新浏览器，页面才会加载新版本。更新过程不会动你的画布数据、姿势图库和手工配置。

下载源（国内优先 · 没有国外网络也能更新）

画布内置 7 路下载源，全部同时探测，谁通就用谁，按下面顺序优先；单个源连不上最多等 8 秒，不会一直转圈。除最后一条 GitHub 直连，其余都不需要国外网络。在更新窗口的「更新源设置」里能看到每个源的实测连通状态，也可以关掉某个源或固定只用其中一个。
